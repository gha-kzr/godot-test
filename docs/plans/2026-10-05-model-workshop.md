# Milestone 9e: Model workshop — plan

Decisions: [`docs/decisions/2026-10-05-model-workshop.md`](../decisions/2026-10-05-model-workshop.md). Branch `milestone-9e` (on top of `main`, which has 9d); one commit per task; tests for the rules (tweaks apply, orphans, rebuild keeps them); no change to how a built scene is used by the game.

1. **Tweaks resource and apply**: `ModelTweaks` (`scripts/data/model_tweaks.gd`, a `Resource`) with `PartTweak` / `JointTweak` / `PoseOverride` entries (path, the fields set, values), a `renames` table; `ModelKit` takes the tweaks the builder gives it (a static `ModelKit.tweaks_for_build` set by the build tool before it calls `Recipe.build()`) and `RigAnimator.build()` applies them first: joints' rest, parts' transform / color / emissive / visibility, then the clips with the pose overrides. `apply` returns the orphans. Tests: each field applies, a rest tweak shifts the clips with it, a rename maps, an orphan is reported and kept.
2. **Build tool**: `tools/build_models.gd` loads `assets/models/<name>.tweaks.tres` when it exists, builds with it, prints the orphans per model; tests that every committed tweaks file has no orphan.
3. **Workshop scene, view**: `scenes/tools/model_workshop.tscn` + script: one model on a tile in the battle's light (reuse the model stage's environment and camera), `model=knight` argument, orbit / zoom, a tree of joints and parts, selection highlighted.
4. **Workshop scene, editing**: sliders (position, rotation, scale) and color / emissive / hidden for a part, rest position / rotation for a joint; edits are live on the model and kept as a draft `ModelTweaks`; Undo / Redo, Reset selected, **Save** writes the tweaks file (and rebuilds the scene file); the model reloads when the recipe file is saved.
5. **Workshop scene, animation**: a clip picker and a time scrubber (play / pause, loop); with a clip frozen at a time, joint rotation sliders write a pose override at that time (add / remove a key), shown as markers on the scrubber.
6. **Animation upgrades** (one commit each, judged on the stage): easing on strikes and recoveries; follow-through (head, tail and plume lag); anticipation and squash; two-segment limbs for the heroes first; per-creature attack feel. Each keeps `tests/test_modeling.gd` green (full animation set, closed loops, heights).
7. **Docs and review**: README (the workshop command and tweaks), roadmap row 9e done, backlog entries trimmed, `godot-code-review`.
