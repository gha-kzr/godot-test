# Screens (milestone 5b) — decisions

Second half of milestone 5 ([`2026-09-30-ui-revamp.md`](2026-09-30-ui-revamp.md) settled the theme, icons and battle HUD). Replaces the first-version party screen and run screen from [`2026-09-28-progression.md`](2026-09-28-progression.md) and [`2026-09-29-run-loop.md`](2026-09-29-run-loop.md).

| Decision | Choice | Why | Revisit when |
|---|---|---|---|
| Platforms | Built for **desktop and web first**, then maybe **Android**, later **gamepad** (same platforms). Mouse and keyboard now; nothing hover-only; layouts use anchors / containers (no fixed pixel positions) so they scale; no desktop-only features on the main path (Quit is hidden on web; fullscreen and file access go through settings code that can be skipped per platform); saves stay in `user://` | Keeps every later platform cheap without building it now | Android or gamepad is scheduled |
| Title screen | **Minimal**: name (placeholder "Tower Tactics"), **Play** (opens the hub, where a saved run waits as Continue / Abandon, so Abandon stays reachable), **Settings**, **Quit** (not on web) | Natural home for the name and credits | a real name or art is chosen |
| Hub layout | **One screen**, restyled: hero tabs left, the selected hero's stats and 6 rune slots centre, stash right, Tower / Stages / Continue bar at the bottom | Runes are equipped every session; sub-screens would hide that loop | the active-spell loadout (roadmap) needs its own space |
| Run screen | Restyled, plus a **floor progress strip** (cleared floors, next elite and boss markers) and **party HP bars** | The only place to judge continue or leave | — |
| Settings | **Window mode + UI scale**, **key rebinding** (spell keys, camera, end turn), **credits** (game-icons.net CC BY 3.0 and the rest of `CREDITS.md`), **reset save** with a confirm, **show hints again**; saved in `user://settings.cfg`, separate from the profile so a reset keeps them. No audio until M6 | Covers the roadmap items and the license credit | M6 brings sound |
| First-run hints | Minimalist and removable: the 5a prompt line does moment-to-moment guidance; a **dismissable one-time card** on the first hub visit and the first battle, dismissals stored in the settings file. One small `HintCard` component and one `Hints` helper (ids → dismissed), so removing or extending hints touches nothing else | Low cost now, easy to delete or grow | playtests show players still get lost |
| Small UX items | (i) right click over the HUD cancels aiming, (ii) the selected hero is kept across screens, (iii) newly unlocked spells are listed in the level-up summary, (iv) self-buff turns wording ("lasts N of your turns") | From the M2–M4 reviews; each is small | — |
| Keyboard / focus | Every screen is **focus-navigable** (arrows, Enter, Esc = back), with a consistent **Back** on non-root screens; a test walks each screen with simulated key events | Keeps the gamepad door open for little | — |
