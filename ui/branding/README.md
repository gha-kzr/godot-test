# Branding

The game's own artwork (provided by the project owner). The title and start screens use it:

- `title_image.jpg` (or `.png`) — the title screen's full picture, which carries the game's name; the menu sits under it. 16:9, 1408 × 768 now. Without it the screens show the text title.
- `logo.png` / `logo.jpg` (optional) — a logo shown instead of the text title when there is no title picture.
- `icon.png` — the square emblem used as the project, window and browser-tab icon (`application/config/icon`).

Run `godot --headless --import` after adding or replacing a file. Third-party art goes in `CREDITS.md` with its source and license; this artwork is listed there as the owner's.
